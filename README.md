# Zaheer SK — Natural Language Processing Portfolio

A futuristic, high-performance, interactive 3D portfolio showcasing my coursework, research, and engineering implementations in **Natural Language Processing (CSI 4001)**.

![NLP Portfolio Preview](zaheer_hero.webp)

---

## 🌟 Overview & Highlights

- **Interactive 3D Cylinder Carousel**: 60fps physics-driven 3D cylinder rotating through 10 coursework modules with inertia damping and real volumetric depth.
- **Monochrome Cyberpunk Aesthetics**: Pure black background (`#000000`), glassmorphic panels, metallic silver highlights, and subtle atmospheric glows.
- **JurisGraph Major Project**: Agentic Corrective RAG system for legal document segmentation, rhetorical role labeling (InLegalBERT), hybrid dense-sparse retrieval, and hallucination reduction.
- **Live In-Browser Playgrounds**: Interactive tokenization visualizer, pos-tagging inspector, and terminal demo simulator.
- **Complete Course Retrospective**: 5-stage connected milestone pathway, 3 knowledge synthesis cards, and personal reflection.

## 🚀 Getting Started

To view the portfolio locally:

1. Clone this repository:
   ```bash
   git clone https://github.com/ZEKRAALL-0811/Zaheer_NLP_Portfolio.git
   cd Zaheer_NLP_Portfolio
   ```

2. Open `index.html` in any modern web browser (Google Chrome, Microsoft Edge, Safari, Firefox) or serve via a local static server:
   ```bash
   # Using Python 3:
   python -m http.server 8000
   ```
   Navigate to `http://localhost:8000` to experience the smooth 60fps animations and 3D card cylinder.

## 🛠️ Tech Stack

- **Frontend**: Vanilla JavaScript (ES6+), Modern HTML5, Custom CSS3 Variables, 3D CSS Perspectives (`perspective: 1350px; preserve-3d`), `requestAnimationFrame` render loops.
- **NLP & AI Tooling**: Python, PyTorch, Hugging Face Transformers, InLegalBERT, spaCy, NLTK, FAISS / ChromaDB, Corrective RAG.
- **Design System**: Monochrome Black & Silver (`#000000`, `#ffffff`, `#888888`), Glassmorphism, JetBrains Mono & Inter Tight typography.
